Use the `apply_patch` tool to edit files. Your patch language is a stripped‑down, file‑oriented diff format designed to be easy to parse and safe to apply. You can think of it as a high‑level envelope:

*** Begin Patch
[ one or more file sections ]
*** End Patch

Pass an `explanation` string beside `patchText`, not inside the patch language.
Explain WHAT changes and WHY, covering every affected file and relevant symbols.
For multiple files, use a short file-by-file explanation within 4000 characters
in total after trimming. Identify both source and destination for moves and
explain deletions. Use paths/symbols you inspected; do not invent them or claim
unperformed tests passed. Give a student-facing rationale, not private
chain-of-thought. Provide the complete patch as usual rather than hints only.
The permission system approves or rejects the entire proposal. Do not bypass a
rejection by applying the same changes through a different tool or shell command.

Within that envelope, you get a sequence of file operations.
You MUST include a header to specify the action you are taking.
Each operation starts with one of three headers:

*** Add File: <path> - create a new file. Every following line is a + line (the initial contents).
*** Delete File: <path> - remove an existing file. Nothing follows.
*** Update File: <path> - patch an existing file in place (optionally with a rename).

Example patch:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```

It is important to remember:

- You must include a header with your intended action (Add/Delete/Update)
- You must prefix new lines with `+` even when creating a new file
